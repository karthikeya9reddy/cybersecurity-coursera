1. Introduction to Functions
A function is a reusable block of code that performs a specific task.

Functions help us:
- Avoid writing the same code repeatedly.
- Automate repetitive tasks.
- Make programs easier to maintain and understand.
- Update functionality in one place instead of changing multiple lines throughout a program.
Types of functions
Type	Description	Example
Built-in	Already available in Python	print(), type()
User-defined	Created by the programmer	greet_employee()

2. Defining and Calling Functions
Python uses the def keyword to define a function.
def greet_employee():    print("Welcome! You are logged in.")greet_employee()



Output:
Welcome! You are logged in.


Key syntax:
- def — Defines the function.
- greet_employee — Function name.
- () — Parentheses for parameters.
- : — Marks the beginning of the function body.
- Indentation — Identifies code belonging to the function.
- greet_employee() — Calls (executes) the function.
Important: Defining a function does not execute its body. You must call it.
3. Parameters and Arguments
Functions can accept information through parameters.
- Parameter: A variable declared in a function definition.
- Argument: An actual value passed when calling the function.
def greet_employee(name):    print("Welcome", name)greet_employee("Charley")



Output:
Welcome Charley


Here:
- name → Parameter
- "Charley" → Argument
Multiple parameters
def greet_employee(first_name, last_name):    print("Welcome", first_name, last_name)greet_employee("Kiara", "Carter")



Output:
Welcome Kiara Carter


Multiple parameters and arguments are separated by commas. Positional arguments are assigned in the order provided.
4. Return Statements
The return keyword sends a value from a function back to the code that called it.
def calculate_fails(total_attempts, failed_attempts):    fail_percentage = failed_attempts / total_attempts    return fail_percentagepercentage = calculate_fails(4, 2)print(percentage)



Output:
0.5


Here, 0.5 represents 50% of login attempts.
Cybersecurity example: Failed login detection
def calculate_fails(total_attempts, failed_attempts):    return failed_attempts / total_attemptspercentage = calculate_fails(4, 2)if percentage >= 0.5:    print("Account locked")



Output:
Account locked


This is a simplified learning example. Real account-lockout policies generally require more than a single failure percentage.
print() vs return
print()	return
Displays output	Sends a value back
Mainly used for displaying information	Used for further calculations and decisions
Returns None	Returns the specified value
Does not end the function	Immediately exits the function

Remember: Any statements after an executed return in the same function call will not run.
5. Global and Local Variables
Variable scope determines where a variable can be accessed.
Global variables
Defined outside a function and accessible throughout the module, including within functions.
username = "elarson"def identify_user():    print(username)identify_user()



Output:
elarson


Local variables
Defined inside a function and normally accessible only within that function.
def greet_employee():    username = "bmoreno"    print(username)greet_employee()print(username)  # NameError



The variable username is local to greet_employee().
Global and local variables with the same name
username = "elarson"def greet():    username = "bmoreno"    print("Inside:", username)greet()print("Outside:", username)



Output:
Inside: bmoreno
Outside: elarson


The local variable does not modify the global variable.

Best practice: Prefer passing values through parameters rather than depending on global variables.
6. Python Built-in Functions
Built-in functions can be used without defining or importing them.
Function	Purpose	Example	Result

Nested function calls
One function's result can be passed into another function.

Output:
<class 'str'>


Execution order:

Find the data type
<class 'str'>
Returned result
print()
Displays the returned result

The inner function runs first, and its return value is passed to the outer function.
7. The sorted() Function
The sorted() function returns a new sorted list without modifying the original list.
time_list = [12, 5, 30, 8]print(sorted(time_list))print(time_list)



Output:
[5, 8, 12, 30]
[12, 5, 30, 8]


Sorting usernames:
usernames = ["zara", "alex", "mike"]print(sorted(usernames))



Output:
['alex', 'mike', 'zara']


Important:
- Default sorting is ascending.
- Strings are sorted lexicographically.
- sorted() returns a new list.
- Incompatible mixed types, such as integers and strings, cannot be sorted directly in Python 3.

2. Importing Modules
The import keyword makes module functionality available to your program.
Method 1: Import an entire module

Output:

When importing the entire module, use:

module_name.function_name()
Method 2: Import specific functions

Output:

When importing specific functions, you can call them directly without the module name.

4. Code Readability and PEP 8
Code readability means writing code that other programmers, including your future self, can easily understand.

PEP 8 (Python Enhancement Proposal 8) is Python's official style guide.

It provides recommendations for:
- Consistent indentation.
- Clear comments.
- Readable variable and function names.
- Proper spacing and code formatting.
- Consistent coding conventions.
PEP 8 is mainly a style guide, not a set of mandatory Python syntax rules.
5. Comments in Python
Comments explain the purpose or reasoning behind code. Python ignores comments when executing a program.
Single-line comments
Use #:
# Lock the account after more than 5 failed login attemptsfailed_attempts = 6if failed_attempts > 5:    print("Account locked")



Multi-line comments
Use multiple # lines:
# This function calculates the remaining login attempts.# It accepts the maximum attempts and attempts already made.# It returns the number of remaining attempts.def remaining_login_attempts(maximum, attempts):    return maximum - attempts



Docstrings
Docstrings use triple quotes (""") and document functions, classes, and modules.
def remaining_login_attempts(maximum, attempts):    """Calculate the number of remaining login attempts."""    return maximum - attempts



Unlike ordinary comments, docstrings can be accessed by Python documentation tools.

Best practices: Keep comments short, meaningful, accurate, and updated when code changes. Explain why something is done when that reasoning is not obvious.
6. Indentation in Python
Indentation means adding spaces at the beginning of a line.

It is essential because Python uses indentation to determine which statements belong to a code block.

PEP 8 recommends 4 spaces per indentation level.
Example: Nested conditional inside a loop
count = 0login_status = Truewhile login_status:    print("Try again.")    count += 1    if count == 4:        login_status = False



Understanding indentation

Loop block: 4 spaces

Nested block: 8 spaces


Incorrect indentation can produce an IndentationError or change how the program executes.
7. Maintaining Correct Python Syntax
Syntax refers to the rules that determine how valid Python code must be written.

Colons in headers
Python requires a colon (:) at the end of function, conditional, and loop headers.
def greet():    print("Hello")if True:    print("Access granted")for i in range(3):    print(i)



Common syntax mistakes
Mistake	Correction
Missing :	Add colon after if, for, while, or def header
Missing indentation	Indent the code block
Unclosed quotation marks	Close string quotes
Incorrect Boolean	Use True or False, not true or false
Missing commas in lists	Separate elements with commas


8. Cybersecurity Practical Example
A simple Python script to analyse failed login attempts using the statistics module.
from statistics import mean, median# Failed login attempts recorded across five daysfailed_logins = [2, 4, 3, 12, 4]# Calculate the average and middle valueaverage = mean(failed_logins)middle = median(failed_logins)print("Average failed attempts:", average)print("Median failed attempts:", middle)# Flag unusually high values for reviewfor attempts in failed_logins:    if attempts > 10:        print("Investigate:", attempts, "failed attempts")



Output:
Average failed attempts: 5
Median failed attempts: 4
Investigate: 12 failed attempts


This example combines module imports, built-in functions, comments, loops, conditionals, and proper indentation.

The threshold of 10 is illustrative, not a universal security rule.
