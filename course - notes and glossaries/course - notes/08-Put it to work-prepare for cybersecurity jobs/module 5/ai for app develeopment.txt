Cybersecurity Notes — Vibe Coding & AI App Development
Google Cybersecurity Professional Certificate · Course 8: AI in Cybersecurity

Topics: Vibe coding, agentic AI, app planning, prototyping, testing, debugging, deployment, and responsible AI.
1. What Is Vibe Coding?
Vibe coding is the process of using natural-language instructions to build applications with AI assistance.

Instead of manually writing all the code, you describe the application's requirements, functionality, and expected results. AI generates and modifies the implementation.

Agentic AI goes beyond generating responses by performing tasks such as writing code, creating interfaces, and connecting application components under human supervision.

Important: AI can generate an application, but you must still verify its functionality, security, and reliability.
2. Identifying the Right App Idea
Not every problem needs an application. The course recommends targeting repetitive workflow bottlenecks.
Factor	What to consider
Frequency	How often does the task occur?
Time spent	Does it consume significant time?
Repetitiveness	Does it follow consistent steps?
Inputs and outputs	Are they predictable?
Complexity	Can the app operate independently, or does it require integrations?

Best candidates: Tasks that are frequent, repetitive, clearly defined, and have consistent inputs and outputs.
3. Three Phases of Vibe Coding

Phase 1 — Planning & Prototyping

Define the problem, requirements, rules, interface, and expected behavior before generating code.




Phase 2 — Testing & Debugging

Test the prototype, identify failures, request fixes, and repeat until the requirements are satisfied.




Phase 3 — Deployment

Prepare the app for users, verify functionality, configure access permissions, and share or publish it.



4. Planning Before Writing Code
Use AI as a planning partner to establish:
- Application purpose, scope, and requirements.
- Input data and expected output.
- Processing logic and security rules.
- User interface and features.
- Edge cases and limitations.
You can ask AI to interview you about missing requirements, then consolidate the decisions into a single detailed build prompt.

Course example: A security analyst builds a threat assessment app that reads access logs, compares them against an escalation playbook, and produces a severity scorecard.
5. Testing, Debugging & Iteration
Iteration is the repeated process of testing, identifying problems, making changes, and testing again.

A useful debugging approach is to describe:

Expected behavior → Actual behavior → Required correction
Example
An app correctly identifies a high-severity threat, but its interface displays a green status.

The developer instructs AI to ensure the severity label, colors, and visual indicators match the actual assessment.
Essential testing practices
- Test all important features.
- Check expected, unexpected, and invalid inputs.
- Verify that AI outputs are accurate.
- Inspect error messages and application logs.
- Test after every major change.
Hallucination: AI-generated information that is inaccurate or fabricated. This is particularly important to detect in security assessment applications.
6. Deploying and Sharing an App
Before sharing an app, review it from the perspective of a first-time user.

Remove confusing or unnecessary elements, simplify explanations, and ensure important results are clearly visible.

Security requirement: Check access permissions and organizational data policies before sharing an app that processes sensitive logs or incident information.
7. Responsible AI Development
AI-generated applications require human oversight.

Review generated code and outputs, test security-sensitive behavior, and follow organizational policies before deploying or sharing.

Remember: A working prototype is not automatically a secure, production-ready application.

Five essential rules
1. Plan first: Define what the application must accomplish before generating code.
2. Start small: Build a manageable first version before adding complexity.
3. Test thoroughly: Check normal inputs, edge cases, and incorrect outputs.
4. Iterate: Describe problems clearly and verify that AI-generated fixes work.
5. Deploy responsibly: Protect sensitive information, review permissions, and test the experience for new users.
Key takeaway: Vibe coding enables you to move from simply using AI to building reusable software with AI. The most important skills are planning, communicating clear requirements, testing, debugging, and supervising the final result.
