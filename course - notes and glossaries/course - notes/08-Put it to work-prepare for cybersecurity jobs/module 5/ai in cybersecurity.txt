1. Introduction to Artificial Intelligence
Artificial Intelligence (AI) refers to computer systems capable of performing tasks commonly associated with human intelligence.

Generative AI (Gen AI) is a type of AI that can create content such as text, code, images, and other media.
Three main capabilities
Capability	Example
Understand information	Summarize long security reports or explain frameworks
Create content	Generate code, documentation, and reports
Improve work	Identify coding bugs and suggest improvements

Examples of generative AI tools include Gemini, ChatGPT, and Microsoft Copilot.
Important AI terminology
Term	Meaning
AI model	Technology that processes inputs and generates responses
AI application	Interface used to interact with AI models
Prompt	Instructions provided to an AI
Input	Information supplied to the AI, including text and files
Output	Content generated by the AI
Temperature	Setting influencing output randomness and variability
Iteration	Refining a prompt to improve results

Temperature: Lower settings often produce more consistent outputs, while higher settings allow greater variation. This does not guarantee factual accuracy.
2. Effective Prompting — T-C-R-E-I Framework
The course introduces a five-step framework for writing effective prompts.
T

Task

Clearly state what the AI should do, including audience and output format



C

Context

Provide relevant background and requirements



R

References

Provide supporting documents, examples, or source material



E

Evaluate

Examine the output for accuracy, relevance, and completeness



I

Iterate

Refine your instructions and repeat until the result improves



Memory trick: Thoughtfully Create Really Excellent Inputs.
Example cybersecurity prompt
Act as a junior SOC analyst.

Explain three common indicators of a phishing
attack, their potential impact, and appropriate
defensive actions.

Present the results in a table using beginner-
friendly technical explanations.


A good prompt is clear, specific, and provides enough context without unnecessary information.
3. AI Applications in Cybersecurity
Understanding security frameworks
AI can help simplify complex security standards such as NIST SP 800-53.

The course uses NIST SP 800-53 Revision 5, control SI-5, which concerns security alerts, advisories, and directives.

AI can help explain the control, discuss practical implementation, and identify relevant control enhancements.

Always verify control descriptions against official documentation and applicable organizational requirements.
Identifying and debugging code
AI can review Python scripts to identify syntax problems, logic errors, exceptions, and potential improvements.

Course example: ZeroDivisionError

A login-analysis script calculates:
login_ratio = today_logins / average_logins



If average_logins is zero, the program raises ZeroDivisionError.

A simple defensive check:
if average_logins == 0:    print("Cannot calculate login ratio")else:    login_ratio = today_logins / average_logins    print(login_ratio)

AI can also add explanatory comments, suggest refactoring, and identify possible performance problems.

Remember: AI-generated corrections must be reviewed and tested before use.
Understanding vulnerabilities
AI can explain security weaknesses, their impact, and potential mitigations.
Vulnerability	Explanation
SSRF	Server-Side Request Forgery: tricks a server into making unintended requests
Injection	Untrusted input affects the execution of commands or queries
Cryptographic failures	Weaknesses in encryption or protection of sensitive data
Broken access control	Users can access resources or perform actions without proper authorization

AI can provide initial guidance, but remediation should be checked against trusted sources and the organization's security policies.
Prioritizing security alerts
AI can assist analysts in interpreting IDS alerts and deciding which ones deserve further investigation.

An AI-assisted analysis might consider:
- Severity and potential impact.
- Importance of the affected systems.
- Evidence of suspicious activity.
- Relationships between multiple alerts.
- Organizational incident response procedures.
For example, multiple SYN flood alerts may require investigation to determine whether they represent a denial-of-service attempt or are related to other suspicious activity.

Important: Consult the incident response plan first. AI-generated recommendations support, rather than replace, analyst judgment.
4. Human-in-the-Loop (HITL)
Human-in-the-loop is an approach where people review, verify, and refine AI-generated results.

It is essential in cybersecurity because AI can produce inaccurate, incomplete, or outdated information.
Responsible AI practices
1. Verify AI-generated information against trusted sources.
2. Test generated code before using it in production.
3. Follow organizational data-handling policies.
4. Avoid entering confidential information or sensitive logs into unapproved AI tools.
5. Keep human oversight over significant security decisions.
Key lesson: AI is a cybersecurity assistant, not a replacement for professional judgment.

Five essential rules to remember
1. TCREI: Write clear prompts, evaluate the output, and refine when necessary.
2. Use AI for assistance: Summarizing reports, understanding frameworks, debugging, and investigating alerts.
3. Protect sensitive data: Never share confidential organizational information with unapproved AI tools.
4. Verify everything important: AI can make mistakes, particularly when interpreting vulnerabilities or suggesting security fixes.
5. Keep humans responsible: Final security decisions require professional judgment and established procedures.
