Linux Notes: Filtering Data with grep, Pipes, and find
1. Filtering in Linux
Filtering means selecting specific information that matches a condition. Security analysts use filtering to find errors in logs, locate suspicious files, and investigate possible malware.
2. grep — Search file contents
grep searches a file and prints lines containing a specified string.
Syntax:
grep "search_term" filename


Examples:
grep OS updates.txt
grep error time_logs.txt
grep jhill Q2_deleted_users.txt


- First argument: the text to search for.
- Second argument: the file to search.
- Output: matching lines only.
3. Piping (|)
Piping sends the standard output of one command as standard input to another command.
Think of it as passing the result of one command into the next.
ls
Lists files and directories

Pipe: |

grep users
Filters names containing users


Example:
ls /home/analyst/reports | grep users


This lists only the names containing users from the directory listing.
Remember: | is a general tool for connecting commands, not just for filtering.
4. find — Search for files and directories
The find command searches a specified directory and its subdirectories using criteria such as name or modification time.
Important options
Command	Meaning
find /home/analyst/projects	Lists items found under the specified directory
find /home/analyst/projects -name "*log*"	Finds names containing log, case-sensitive
find /home/analyst/projects -iname "*log*"	Finds names containing log, case-insensitive
find /home/analyst/projects -mtime -3	Finds items modified within the past three days
find /home/analyst/projects -mtime +1	Finds items modified more than one day ago
find /home/analyst/projects -mtime -1	Finds items modified less than one day ago
find /home/analyst/projects -mmin -30	Finds items modified within the past 30 minutes
Wildcards: * represents zero or more characters.
For example, "*log*" matches names such as logs, server_log.txt, and catalog.
- -name is case-sensitive.
- -iname is case-insensitive.
- -mtime measures modification time in days.
- -mmin measures modification time in minutes.
Difference: grep searches inside file contents, while find searches for files and directories that meet criteria.
