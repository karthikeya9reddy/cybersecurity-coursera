🖥️ Operating Systems — Notes
1. What is an Operating System?
An Operating System (OS) is the interface between the user, applications, and computer hardware.
It allows humans to interact with the computer without needing to communicate directly in binary (0s and 1s).
Main jobs of an OS
- Runs and manages applications
- Manages hardware
- Allows multiple applications to run
- Manages devices such as:
  - Keyboard
  - Mouse
  - Printer
- Manages files and data
- Manages user access/authentication
- Provides an interface between humans and computers
Simple mental model:
User → Operating System → Hardware
🔐 2. Why OS is Important in Cybersecurity
Security analysts need to understand operating systems because many security tasks happen at the OS level.
Examples:
- Managing user access
- Configuring firewalls
- Setting security policies
- Enabling antivirus/virus protection
- Auditing systems
- Monitoring logs
- Detecting unusual behavior
- Protecting files and data
Key idea:
Securing the OS is a major part of securing the computer.

Remember:
Linux = Open source + heavily used in cybersecurity.

⚠️ 5. Operating System Vulnerabilities
No operating system is completely free from security vulnerabilities.
One of the most important ways to protect an OS is:
Keep the OS and its components updated.

Updates often contain security fixes.
🕰️ 6. Legacy Operating Systems
A legacy OS is an outdated operating system that is still being used.
Why do organizations still use them?
Sometimes newer operating systems aren't compatible with older software or equipment.
This is especially common with systems using embedded software.
Why are legacy OSs dangerous?
They may:
- No longer receive security updates
- Have known vulnerabilities
- Be vulnerable to newer attacks
Cybersecurity takeaway:
Old OS → No/limited updates → Known vulnerabilities → Higher risk
🐛 7. Other OS Vulnerabilities
Even an updated OS can still have vulnerabilities.
Security professionals can monitor vulnerability databases and security advisories.
Examples mentioned in the course:
- Microsoft Security Response Center (MSRC) → Microsoft vulnerabilities
- Apple Security Updates → Apple vulnerabilities
- CVE reports for Ubuntu → Ubuntu/Linux vulnerabilities
- Google Cloud Security Bulletins → Google Cloud vulnerabilities
You don't need to memorize these websites right now. Understand that vendors publish information about known vulnerabilities and security updates.
